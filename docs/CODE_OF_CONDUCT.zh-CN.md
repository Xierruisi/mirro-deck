# 社区行为准则

**简体中文** | [English](CODE_OF_CONDUCT.md)

MirroDeck 希望为所有参与者提供友善、专业且安全的协作环境，不因经验、身份、背景或观点不同而区别对待。

## 期望行为

- 尊重他人，围绕事实和技术问题讨论；
- 接受建设性反馈，并清楚说明不同意见；
- 关注社区与用户的整体利益；
- 主动保护日志、截图和复现材料中的隐私信息；
- 发现误解或伤害时及时澄清、道歉并改进。

## 不可接受的行为

- 骚扰、侮辱、威胁、歧视或人身攻击；
- 未经许可公开他人的私人信息；
- 性暗示内容或不受欢迎的关注；
- 刷屏、恶意破坏、故意误导或持续扰乱讨论；
- 其他在专业协作环境中明显不适当的行为。

## 适用范围与处理

本准则适用于仓库、Issue、Pull Request、Discussion，以及代表本项目参与的其他公开或私下互动。

维护者可以编辑或移除不当内容，并根据严重程度采取提醒、警告、临时限制或永久禁止参与等措施。处理时会尽量兼顾事实、隐私和受影响者的安全。

如需报告违反准则的行为，请使用 GitHub 提供的内容举报与屏蔽功能。若报告包含安全漏洞、隐私数据或其他不宜公开的信息，请通过仓库的 GitHub Security Advisory 私下提交，不要创建公开 Issue。维护者会谨慎处理报告，仅在调查和处置所必需的范围内共享信息。
